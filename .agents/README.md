## Maintenance contract

At the start of a task, read the repo-level instructions and the relevant component guide. When a change crosses components, read each owner guide. Before finishing, compare any touched guide against changed source paths and update stale guidance in the same change. Add a specialist guide when a new key component has a distinct owner and workflow. These files are maintained by agents as code evolves; they do not grant background or autonomous write access.
